2022A 波浪能模拟赛复盘：从“算出结果”到“建立可信的物理模型”

这次模拟做的是 2022 年全国大学生数学建模竞赛 A 题“波浪能最大输出功率设计”。

题面看起来很规整：先建立浮子和振子的垂荡模型，再优化 PTO 阻尼；随后加入纵摇自由度，最后联合优化直线阻尼器和旋转阻尼器。真正开始做以后才发现，这类偏物理的 A 题，最困难的地方通常不是把微分方程交给求解器，而是回答下面这些问题：

  • 坐标原点应该放在哪里，重力和静浮力为什么没有出现在增量方程中？
  • 附件中的“附加质量”和“附加转动惯量”应该加到哪里？
  • 优化的是从零初态开始的一段平均功率，还是长期周期稳态功率？
  • 非线性阻尼下，怎样判断系统已经进入稳态？
  • 题目没有直接给出的物理转动惯量，应该如何从几何结构补全？
  • 一个数值结果通过了求解器，是否就足以写进论文？

这篇文章不再复述四问的完整答案，而是记录这次模拟中最值得带到下一场比赛的建模经验。

一、先规定模拟边界：独立完成，再看优秀论文

本次模拟采用了一个很重要的规则：在四问模型、程序、图表和初稿封板以前，只读取官方题面、附件和空白结果模板，不查看已有题解、优秀论文和网络结果。

这样做会降低前期速度，但能暴露我们的真实能力。哪些公式是自己能够推出来的，哪些参数口径容易误解，哪些数值验证是主动想到的，都不会被参考答案提前遮住。

优秀论文是在独立求解结束后才加入工作区的。赛后对比的作用也不是“把自己的答案改成和别人一样”，而是检查三件事：

  1. 核心物理关系是否一致；
  2. 是否遗漏了重要推导或结果解释；
  3. 正文叙事是否让读者能够从假设一路跟到结论。

这次对比以后，一个很明显的结论是：我们的数值验证和优化口径已经比较严格，但优秀论文在“坐标—几何—能量—方程—结果”这条叙事链上更连贯。以后不能只追求公式正确，还要让评委看见公式是怎样生长出来的。

二、问题一最大的坑：不是列方程，而是确定平衡基准

1. 不能把附件参数直接全部塞进方程

问题一只考虑垂荡，但附件同时给出了垂荡、纵摇、附加惯性、兴波阻尼和恢复力矩等多类参数。如果不先做“题目—情形—参数”的映射，很容易把后面问题的参数提前混入模型。

这次采用的做法是先建立参数来源表，只保留当前问题真正需要的量，并对每一个派生参数写出来源。例如浮子的垂荡惯性不是浮子质量本身，而是

Mf=mf+ma,

其中附加质量只进入浮子的垂荡惯性项，不能加到振子上。

2. 静水恢复刚度必须先验证水线位置

静水恢复刚度通常写成

kh=ρgAw.

但这里的水线面积 Aw 取决于静水面究竟落在圆柱段还是圆锥段。不能看到半径为 1 m 就直接写 Aw=πR2 。

我们先利用总重量反算排水体积：

Vd=mf+moρ,

再扣除圆锥体积，得到圆柱段的静态吃水约为 2.000 m 。它位于圆柱的 0 到 3 m 范围内，这才证明水线面积确实为 πR2 ，相应的静水恢复刚度才有几何依据。

这一步给我们的经验是：物理公式中的几何量不能凭图猜，必须先证明当前状态处于该公式的适用区间。

3. 为什么重力、静浮力和弹簧预压缩不见了

如果以绝对位置写方程，重力、静浮力和弹簧预压力都会出现；但本题的位移是相对静水平衡位置的增量。平衡点处的常量力已经相互抵消，因此增量势能只保留与位移有关的二次项。

直线弹簧的静压缩量为

δ0=mogk,

平衡长度为 le=l0−δ0 。这些量不会作为常量力重复进入增量方程，但必须保留下来检查弹簧长度是否始终为正。

我们一开始容易把“方程里没有重力”理解成“忽略重力”。实际上，这是坐标平移和静平衡条件的结果。论文中必须把这一层说清楚，否则即使方程正确，也容易让读者怀疑漏项。

4. 量纲检查发现了幂律阻尼的隐含单位

常量阻尼满足

D(vr)=cvr,

因此 [c]=Ns/m 。幂律阻尼写成

D(vr)=a|vr|pvr

以后， a 的单位会随指数 p 变化：

[a]=N(s/m)p+1.

这提醒我们，不能把不同指数下的比例系数都机械地标成普通阻尼系数单位。量纲检查不仅是论文末尾的形式工作，它经常能直接发现模型定义中的问题。

三、问题二最重要的决定：先定义“平均功率”，再谈优化算法

1. 从零初态开始的全程平均不公平

如果直接从零初态积分固定时长，再用全时段平均功率比较不同阻尼参数，结果会混入自由振动衰减过程。不同阻尼参数的暂态持续时间不同，选择不同仿真终点甚至可能改变参数排名。

因此本次把目标明确为稳定周期轨道上一个完整波浪周期的平均输出功率：

P―=1T∫tsts+TPPTO(t)dt,y(ts+T)=y(ts).

这个定义排除了人为选择仿真长度的影响。它也是后面选择频域法和周期射击法的依据。

这次最重要的一条经验是：优化题首先要定义一个可比较的目标口径，而不是先选粒子群、遗传算法或其他优化器。

2. 线性问题没有必要一上来就用智能优化

常量阻尼下，系统是线性定常系统。令稳态响应为

x(t)=ℜ{Xeiωt},

就可以在复频域直接求解响应，并得到平均功率

P―(c)=12cω2|[−1,1]X(c)|2.

这样既没有暂态误差，也把原问题降成了一个有界的一维优化。最后再用全区间扫描、连续优化、解析条件和时域周期解交叉验证，比直接运行一次黑箱算法更可靠。

3. 非线性稳态不能靠“多跑一会儿”来定义

幂律阻尼使系统变成非线性周期受迫系统。最直接的办法是从零初态一直积分，等待相邻周期足够接近；但在二维参数搜索中，这种做法成本很高。部分参数点需要数百个周期才能达到严格稳态，把它直接嵌入全局搜索会浪费大量时间。

解决办法是周期射击法。设一个周期的状态映射为 ΦT ，直接求解

ΦT(y0;a,p)−y0=0.

求得周期初态后，只需再积分一个周期就能计算平均功率。这里改变的是数值求解方式，不是稳态目标本身。

为了兼顾速度和可信度，我们把计算分成三层：

  • 快速射击负责全参数域粗筛；
  • 严格射击负责候选点精修和最终定值；
  • 从零初态出发的长时积分只负责独立复核少量最终候选。

固定哨兵点验证表明，快速设置能够保持候选排序，严格射击与频域或长时基准一致，同时显著降低搜索成本。

4. 边界不是搜索失败，而可能就是答案

幂律阻尼的高功率区域形成了一条参数补偿脊线，并最终走向比例系数上边界。多个内部初值都向边界移动时，不能为了得到“好看的内部最优点”而人为缩小搜索范围，而应单独沿真实边界进行一维精修，并检查向内扰动后功率是否下降。

最终幂律阻尼相对最优常量阻尼的提升只有约 0.29% 。这比“非线性模型一定更好”更有价值：在题设约束和当前速度范围内，额外复杂度带来的收益非常有限，而且最优比例系数已经触及上界。

四、问题三真正困难的地方：补全题目没有直接给出的物理量

问题三增加垂荡和纵摇以后，最容易犯的错误是把附件给出的“纵摇附加转动惯量”直接当成浮子的全部转动惯量。附加转动惯量描述的是流体随结构加速产生的附加惯性，不能取代浮子壳体自身的物理转动惯量。

1. 先锁定几何解释，再计算惯量

题面没有明确说明“圆柱壳体”是否包含顶部端盖。主模型根据密封结构的描述，将浮子视为由圆柱侧壳、圆锥侧壳和顶部圆盖组成的均匀薄壳，按面积分配质量，再利用分部质心和平行轴定理求总质心与转动惯量。

由于这一解释不是官方直接给出的参数，我们没有把它隐藏起来，而是保留“不计顶部端盖”的替代口径做敏感性分析。结果显示纵摇峰值规模只变化约 1% 到 2% ，但低阻尼系统的相位会随时间积累出更明显的差异。

这给出一个很实用的原则：题意存在解释空间时，应把解释写成假设，并用敏感性分析说明它会影响什么、不会影响什么。

2. 小角度近似必须逐项判阶

令浮子纵摇角和振子绝对纵摇角分别为 θf 、 θo ，振子沿中轴的相对滑动量为 u 。从振子质心的精确平面坐标出发，在小角度下展开可得

XO=aθf−dθo+O(2),ZO−ZO,0=xf+u+O(2).

因此一阶模型中，垂荡与纵摇的交叉项是二阶小量，可以分成两个二自由度子系统；但振子的水平速度

X˙O=aθ˙f−dθ˙o

同时含有两个角速度，所以纵摇子系统内部仍存在非对角惯性耦合。相应动能为

Tθ=12(Jf,C+Ja)θ˙f2+12mo(aθ˙f−dθ˙o)2+12Jo,Cθ˙o2.

展开以后， −moadθ˙fθ˙o 就是移动铰轴造成的惯性耦合项。这个负号不是“负惯量”，而是由两个转角正方向与机构几何关系共同决定的。

这次最大的收获不是得到某个惯量数值，而是确认了正确的推导顺序：

对于偏物理的题目，这条链比直接画受力图后凭经验拼矩阵更稳。

五、问题四的经验：先利用模型结构，再做二维搜索

在线性小角度模型中，垂荡和纵摇形成块对角的两个子系统；直线 PTO 只作用于垂荡子系统，旋转 PTO 只作用于纵摇子系统。因此总平均功率可以严格分解为

P―(cz,cθ)=P―z(cz)+P―θ(cθ).

原本看起来是二维联合优化的问题，由此分解成两个独立的一维有界优化。进一步利用阻尼矩阵的秩一结构和 Sherman–Morrison 更新，可以推导无约束最优条件

c0∗=1ω|s|.

最后只需把无约束最优点投影到题目允许的区间，并用全域扫描、二维随机优化和时域周期积分复核。

这一步带来的通用经验是：**优化以前先检查矩阵结构、变量可分性和解析条件。**很多所谓“高维优化问题”，只是还没有把物理模型整理到最合适的形式。

六、一个结果怎样才算“可以写进论文”

这次模拟没有把“程序成功退出”视为结果验收，而是建立了多层验证。

1. 输出网格和积分步长不是同一回事

题目要求按 0.2 s 输出，不代表微分方程应该用 0.2 s 固定步长积分。程序采用高阶自适应积分器和更小的内部最大步长，再在官方网格上输出结果。这样既满足提交格式，也不牺牲积分精度。

2. 至少保留一条独立求解路径

线性问题使用频域解析解和时域积分互相验证；四自由度线性系统还使用矩阵指数解复核完整暂态。非线性稳态则由严格射击和冷启动长时积分交叉确认。

同一个程序把结果重复算两遍不叫独立验证。真正有价值的验证应该在表示形式、算法或误差来源上彼此独立。

3. 能量闭合比“曲线看起来正常”更有说服力

以垂荡系统为例，机械能满足

dEdt=fcos⁡(ωt)x˙f−bx˙f2−D(vr)vr.

右端依次对应波浪输入、兴波耗散和 PTO 输出。对整个时段积分后，输入功、机械能变化和各类耗散应该闭合。它能够同时检查力的符号、功率定义和数值积分，而不仅是检查某一个输出值。

4. 结果文件也需要验收

官方 Excel 结果表不是把数组写进去就结束。我们重新打开导出的工作簿，逐单元格与冻结数据比对，检查公式错误、合并单元格、边框延伸和关键时刻，并保留文件指纹。问题三的表格就暴露过模板边框只预置到前十行的问题，数值没有错，但如果不做视觉检查，正式提交仍会显得不完整。

七、Windows 建模与 Mac 写作：交接必须围绕“唯一事实源”

本次协作中，Windows 侧负责模型、代码、数值结果和正式图；Mac 侧负责 LaTeX 论文。这个分工本身没有问题，真正容易出错的是两端各自保存一套“最终结果”，随后在论文、控制台输出和临时图片之间互相抄数。

后来采用了明确的事实源：

  • 完整序列只认正式结果工作簿或冻结数据；
  • 最优参数和验收状态只认最终汇总文件；
  • 论文图片只从 figures/final/ 引用；
  • Mac 写作只从交接区读取公式、结果、图表索引和复现说明。

Git 提交和拉取过程中也出现过同一论文文件被两端连续修改的问题。经验是不要把同步问题留到论文完成以后统一处理，而应当：

  1. 开始修改前先拉取并确认工作区状态；
  2. 按“模型结果、正文段落、代码附录、摘要优化”拆成小提交；
  3. 明确同一时段由哪一端负责 main.tex；
  4. 冲突解决后重新编译 PDF，不能只看 Git 已经干净；
  5. 不覆盖另一端尚未提交的修改，也不把临时缓存混入正式提交。

这比“发生冲突以后再想办法合并”可靠得多。

八、论文写作暴露出的三个问题

1. 正文不能只有数值，没有理论链

最初的写作更偏向快速交付结果，数值、表格和验证很多，但关键公式之间的解释不够连续。赛后阅读优秀论文以后，我们重新认识到：偏物理题中，理论推导本身就是建模能力的证据。

以后正文应尽量采用下面的顺序：

不能直接从一句“由拉格朗日方程可得”跳到数值矩阵，也不能连续放几张曲线却不解释相位差、相对速度和 PTO 输出之间的关系。

2. 摘要必须逐问给答案

摘要经过几轮修改以后才真正做到四问闭环。早期版本虽然写了使用什么模型、得到什么总体结论，但问题一和问题三缺少题目指定状态的代表性数值。

以后摘要中的每一问至少要包含：

摘要不是目录，也不是“本文完成了四个问题”的说明书。评委应该在第一页就能判断四问是否完成、主要结果是什么、哪一项是文章的亮点。

3. 代码附录应从一开始就进入论文清单

正文完成后才发现相关代码还没有按模板写入文章末尾。后来虽然补齐了四问核心代码，但这说明写作清单只覆盖了正文，没有覆盖完整提交结构。

下一次应在开赛初期就建立论文骨架：摘要、四问正文、参考文献、结果文件说明和代码附录同时占位。代码附录只保留能够说明核心模型和求解流程的入口，不把整个工程无差别粘进论文。

九、下一次模拟直接执行的流程

经过这次模拟，我们把下一场比赛的工作流压缩为以下步骤。

建模开始前

  1. 建立“问题—附件—参数—单位—来源”表。
  2. 明确坐标原点、正方向、平衡基准和初始条件。
  3. 列出官方直接参数、几何派生参数和解释性假设，三者不得混写。

写程序以前

  1. 先写目标函数、约束和评价口径。
  2. 推导量纲、极限情形和能量关系。
  3. 为每个问题设计至少一条独立验证路径。
  4. 区分积分内部步长、诊断网格和官方输出网格。

优化以前

  1. 先看能否得到解析解、频域解或降维结构。
  2. 全域粗筛负责找区域，严格算法负责最终定值。
  3. 显式检查全部边界，不把边界最优误判成算法失败。
  4. 最终点必须做双侧扰动、物理范围和独立算法复核。

写论文时

  1. 每一问形成“分析—推导—求解—结果—解释—检验”的小闭环。
  2. 公式前说明为什么需要它，公式后说明它服务于哪一步。
  3. 图表回答明确问题，不只展示程序输出。
  4. 摘要逐问写出方法、答案和结论。
  5. 正文、参考文献、结果说明和代码附录同步推进。

提交以前

  1. 重新运行核心测试和结果验收。
  2. 回读 Excel、重渲染 PDF、逐页检查图表与公式。
  3. 核对论文数值是否来自唯一事实源。
  4. 清理临时文件后再提交，并完成另一端拉取验证。

十、最后留下三条最重要的经验

如果只把这次模拟压缩成三句话，我会保留下面三条：

  1. 偏物理的 A 题，先把坐标、平衡和能量关系讲清楚，再写微分方程。
  2. 优化结果是否可信，主要取决于目标口径、边界检查和独立验证，而不是优化算法的名字。
  3. 论文不是程序结果的容器；它必须把假设、推导、数值和物理解释连成一条读得懂的证据链。

这次模拟最终完成了四问、正式结果表、图表、LaTeX 论文和代码附录，但更重要的收获，是把一次“做完往年题”变成了下一次可以复用的流程。距离正式比赛越近，越应该少积累零散技巧，多建立这种能够稳定执行的工作方式。
